# A manager chooses the hires: the recorded real run

- `manager.cassette.json`: the evidence (cycle 66, 2026-10-22). The generation-turnover world (a
  hosted made-up market; pod-1 an edge sector, pod-2 noise, pod-3 a crash, two unheld sectors with
  an edge; no mind is told any fate) with the generation, reproduction (second edition) and
  management laws on. Three founding PMs and every hire, each anthropic/claude-haiku-5.5 on its
  own $0.20 key; the firm's manager, `ceo`, anthropic/claude-haiku-5.5 on its own $0.30 key, with
  only the manager's tools (whoami, get_clock, read_board, get_vacancy, pick_hire, get_direction,
  set_direction). 31 steps of 3 days (Sep 1 to Dec 3, 2024), 24 tool calls a wake, thinking
  charged every step. Made with the command
  `uv run python acceptance/manager_chooses_hires.py --write-world DIR` prints.
- What happened: the crash pod's place (freed mid-September, before any month was measured)
  listed one hire, the plain one; the manager said nothing and it stood. At September's end the
  noise PM went; its place listed the law's own hire (a child of pod-1, the fittest), a child of
  hire-1 (the other fit pod) and a plain hire. **The manager picked the law's own hire (c1)** and
  briefed the new PM: "Inherit pod-1's momentum rule (60-day lookback, top 5 of the K universe)
  with the faster 5-day rebalance. Keep thinking costs low and manage drawdown carefully." It
  never wrote a firm direction. Its thinking cost $0.029 over 31 wakes, the centre's; the whole
  run $0.581, every key under its limit.
- `uv run python acceptance/manager_chooses_hires.py` judges it (part B: physics' answers to
  whatever the minds chose) and replays it (IDENTICAL, $0). What physics does when a manager picks
  another hire is proven by parts A and B0, where the choice is forced.
